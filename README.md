# ⚛️ React-Projects

This repository contains a variety of mini projects built using **React.js**. Each project reflects a key concept in frontend development—from component composition and state management to working with APIs and user interactions. These apps are created as part of my learning journey and aim to be clean, responsive, and user-friendly.

---

## 📦 Projects Included

### 🎨 Background Color Changer
Change the background color of the page dynamically with a single click. Demonstrates use of `useState` and event handling.

### 💱 Currency Converter
Real-time currency converter using exchange rate APIs. Focuses on fetching external data and controlled components.

### 🔐 Password Generator
Generate secure passwords with custom length and complexity options. Highlights form inputs, state updates, and conditional rendering.
